# Examples

Synthetic examples showing the PM artifact chain in practice. Each scenario runs from Concept Narrative through PRD to User Stories — the full sequence from initial proposal to Dev-ready handoff.

These are not real client engagements. They are constructed from the B&M OT security research corpus (`ai-knowledge-base/professional/research/ot-security/`) to be realistic in domain and scope, but sanitized for sharing.

## How to read these

1. **Concept Narrative** — the initial proposal that clears evaluation. 2-pager equivalent. Shows the problem, goals, and direction. This is what the intake and evaluation process produces.
2. **PRD** — the development spec. 7-section format. This is what Dev receives at the PM→Dev handoff.
3. **User Stories** — engineering-ready stories with inputs, outputs, and acceptance criteria. This is what Dev picks up as tickets.

The Concept Narrative answers "should we build this?" The PRD answers "what are we building?" The User Stories answer "how does Dev execute?"
